A toolbox, not a trap

Enough structure to think clearly.

Keel is for people who want the reach of a modern workspace and the understandable ownership model of a file on a machine they chose.

01

Write without rearranging your brain

Blocks, Markdown shortcuts, tasks, code, images, focus mode, split view, and continuous reading live in one calm editor.

02

Connect what matters

Use wikilinks, backlinks, tags, daily notes, and a stable graph to find the path between ideas.

03

Shape work five ways

Switch the same records between table, list, kanban, timeline, and mind-map views without duplicating the data.

04

Move when you want

Export the complete workspace, restore it elsewhere, or move a local install into Docker. Your deployment is a choice, not a sentence.

Ownership with honest edges

You choose where the notebook lives.

Run Keel on one computer, a home server, or a VPS. Keep it private over Tailscale or place it behind your own HTTPS domain. Optional cloud services can provide sign-in, backup copies, imports, or a OneNote mirror, but none is required to open the app.

See how storage works
01

Plain storage model

SQLite is the default. PostgreSQL is available for managed hosts. The app tells you which one you are using.

02

Backups you can test

Create snapshots, add a passphrase for encryption, and copy them to a folder or an optional storage provider.

03

No silent promises

The live database is not application-encrypted. Use disk encryption when you need storage-at-rest protection.
