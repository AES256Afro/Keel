# Contributing

Bug reports, security reports, documentation feedback, and feature ideas are
welcome.

Keel is not accepting unsolicited code contributions yet. Please do not open a
pull request unless the repository owner has invited it first. Keeping the
copyright chain simple is important while the project's commercial licensing
model is being established.

- Report bugs with a minimal reproduction and your Keel version.
- Propose features by explaining the user problem before prescribing a design.
- Report vulnerabilities privately using GitHub's security advisory form. Do
  not put exploit details in a public issue.

An invited code contribution will require a separate contributor agreement
before it can be merged.
